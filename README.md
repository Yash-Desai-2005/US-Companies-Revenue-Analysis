# US Companies Revenue Analysis

## Project Overview

This project analyzes US companies based on their revenue, employee count, industry, and revenue growth.

The data was collected from a public webpage using Python and BeautifulSoup. Pandas was used for data cleaning and analysis, and Matplotlib was used to create visualizations.

## Objectives

- Collect company data using web scraping
- Clean and prepare the dataset
- Find the top 10 companies by revenue
- Calculate average company revenue
- Analyze companies by industry
- Find the company with the highest employee count
- Calculate average revenue by industry
- Create charts to visualize the results

## Tools & Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains information about 100 companies.

The main columns include:

- Rank
- Company Name
- Industry
- Revenue (USD millions)
- Revenue Growth
- Employees
- Headquarters

## Data Cleaning

The following cleaning tasks were performed:

- Removed commas from revenue values
- Converted revenue into numeric format
- Removed percentage symbols from revenue growth
- Converted employee counts into numeric format
- Checked for missing values
- Checked data types

## Analysis

The project includes the following analysis:

1. Top 10 Companies by Revenue
2. Average Revenue
3. Companies by Industry
4. Company with Highest Employee Count
5. Industry-wise Average Revenue

## Data Visualization

Matplotlib was used to create visualizations for:

- Top 10 Companies by Revenue
- Companies by Industry
- Average Revenue by Industry
